O QUE É
  Coletor completo do atacadao.com.br. Fala direto com a API da
  plataforma VTEX (por baixo do site) — descobrimos que dá para
  paginar de verdade usando um truque de cache-buster. Gera os
  mesmos JSONs do Soudaki e grava no Neon com loja_id = 3.

  Diferença importante p/ o Soudaki: este NÃO precisa de IP
  brasileiro nem cloudscraper — a API da VTEX responde de qualquer
  lugar. Só o `requests` é necessário.

  IMPORTANTE: esta pasta já vem com a COLETA COMPLETA FEITA
  (29/10/2026): 4.871 produtos e 4.871 preços em output\.
  Você pode pular direto para o PASSO 3 (integrar no Neon).
  Para recolher do zero: apague a pasta output\ e siga os passos.

  MEDICAMENTOS FORA: decidimos (out/2026) não incluir a drogaria —
  remédio não é item de cesta de supermercado. Além disso os slugs
  de drogaria do site são "fantasmas" (a busca devolve o catálogo
  inteiro). O coletor tem um guarda que detecta isso sozinho.

PASSO 2 — COLETAR TUDO (só se quiser recolher; ~15 min,

PASSO 3 — INTEGRAR NO NEON
  Copie a pasta para <repo>\scraper\atacadao\ (mesmo lugar do
  soudaki_v2), com o .env do Neon na raiz do repo, e:

  PS> python scrap_atacadao.py --integrar --dry-run   <- SIMULA, me mostre
  PS> python scrap_atacadao.py --integrar             <- grava de verdade

  O dry-run mostra: quantos casaram por EAN, por nome e quantos
  produtos novos criaria. Grava com loja_id = 3 (Atacadão).
